# 画像アップロード運用ガイド

## 1. 目的

店舗画像・ブランド画像・プロフィール画像を安全かつ簡単に差し替えるための手順書です。

## 2. 置き換え対象

- ブランドロゴ
- ヒーロー画像
- 店舗画像
- 女の子プロフィール画像
- ギャラリー画像

## 3. 実運用チェックリスト

### 3-1. ブランド画像

- [ ] ロゴファイルが `src/main/resources/static/images/brand/logo.svg` にある
- [ ] ヒーロー画像が `src/main/resources/static/images/brand/hero-banner.svg` にある
- [ ] 参照元のHTMLが `/images/brand/logo.svg` / `/images/brand/hero-banner.svg` を使っている
- [ ] ブラウザで表示確認済み

### 3-2. 店舗画像

- [ ] 管理画面にログイン済み
- [ ] 対象店舗の「画像」セルにあるアップロードフォームを確認
- [ ] 対象ファイルを選択
- [ ] 画像が変わったことを確認
- [ ] タブやスマホ幅でも表示確認

### 3-3. プロフィール画像

- [ ] 各在籍者の編集画面で画像を確認
- [ ] ほかの画像とトーンが揃っているか確認
- [ ] 形式が JPG / PNG / SVG / WebP で問題ないか確認

## 4. 画像サイズの目安

- ロゴ: 220px 〜 480px 角度よく収まるサイズ
- ヒーロー画像: 1280x720 以上
- 店舗画像: 1200px 以上の縦横比を守る
- ギャラリー画像: 800px 〜 1400px で軽量化

## 5. 画像形式

推奨:
- SVG（ロゴやアイコン）
- JPG（写真）
- WebP（軽量化に有利）

注意:
- 透過ロゴは SVG を優先
- 大きすぎる画像は変換または圧縮を推奨

## 6. 運用メモ

- 画像は原則、`brand` フォルダまたはアップロード済みの画像管理に従う
- 既存の置換用プレースホルダーを残して本番画像に差し替える運用が安全
- ロゴやヒーロー画像の差し替えは、再デプロイ後に表示確認を必ず行う
